# notes/

Knowledge that isn't tied to one project.

- `research/`: things you looked into, with sources and dates.
- `briefs/`: briefs you've written for yourself or for agents before a piece of work starts.
- `workflows/`: **lessons learned that apply across projects.** When an agent (or you) learns
  something the hard way, it goes here so the next project starts smarter.

A fact about *you* goes in `memory/`. A lesson about *how to do the work* goes in `notes/workflows/`.
