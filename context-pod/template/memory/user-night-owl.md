Alex does deep work between 21:00 and 01:00 local time and keeps mornings free until about 10:30.

**Why:** tried a 7am routine from 2026-01-05 to 2026-02-15; output dropped and sketching stopped. Late evenings match Sam's night shifts, so the house is quiet.

**How to apply:** suggest hard tasks for the evening and light ones (email, planning) for late morning. Don't propose early meetings. When a plan has a daily schedule, start it at 10:30.
