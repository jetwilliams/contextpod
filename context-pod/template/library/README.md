# library/

Reusable things that more than one project uses. Agents may read from here but should only add
to it when asked.

- `brand/`: your logos, colours, fonts, voice and tone notes.
- `refs/`: reference material you've collected (articles, saved explanations, datasheets), each with a note on where it came from.
- `templates/`: reusable document templates (proposals, invoices, briefs, checklists).

Large binary files (images, video, fonts) are fine here, but consider keeping them out of git or
using Git LFS.
