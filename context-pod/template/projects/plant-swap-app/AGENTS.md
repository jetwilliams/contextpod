# AGENTS.md: plant-swap app

Read the pod's root `AGENTS.md` first; its hard rules apply here too. This file adds the project brief.

## Brief

Build and maintain a small web app where people in one town list plant cuttings and arrange swaps.
First public demo: **2026-04-18** at the garden club. Alex is learning to code through this
project, so explaining matters as much as shipping.

## Rules for this project

- Work only inside this folder.
- Stack is fixed: Python standard library + SQLite, server-rendered HTML. No new dependencies
  without asking.
- Explain each change in plain words in your reply, with the smallest example that shows it.
  (Alex learns from worked examples; see `../../personal/preferences.md`.)
- Before the demo, anything on the demo path (sign-up, listing, photo upload) beats new features.
- No in-app messaging (decided 2026-02-03; see `README.md`).
- Never put real user emails or addresses in test data. Use `example.org` addresses.
