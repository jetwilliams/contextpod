# Journal

One file per day, named `YYYY-MM-DD.md`. Write it for your future self, not for an AI.

- Start with a two-line summary, so a model (or you, in a year) can skim.
- Use absolute dates. "Yesterday" means nothing in six months.
- When a journal entry contains a lasting fact ("I've decided to stop taking rush jobs"),
  copy that fact into a memory file. The journal is the diary; `memory/` is the distilled version.
- Private by default. Pack journal entries only when the task really needs them.
