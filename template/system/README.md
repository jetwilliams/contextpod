# system/

Scripts and notes for the machine the pod lives on: backups, starting and stopping the services
your projects run, setup notes for rebuilding on a new computer.

- `backup.sh`: example backup of the pod to an external drive (see `docs/privacy.md` in the
  context-pod repo for the full strategy).
- `SETUP.md` (yours to write): what's installed and how to rebuild the machine.

Agents should treat anything here as needing your OK to run, because it touches the whole machine.
