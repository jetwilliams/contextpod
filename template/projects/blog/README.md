# Blog: build logs

> Example: replace with your own.

**Summary:** short build-log posts about the projects in this pod, published at
[jetworks.io](https://jetworks.io). Drafts are written here; publishing happens by hand.

## Why

- Documenting builds is how they help other people (and future me).
- A post is a natural checkpoint: it forces the notes and photos into shape.

## How a post gets made

1. A project milestone lands; its `notes/` hold photos and rough notes.
2. The agent drafts a post in `drafts/` from those notes.
3. The owner edits and approves.
4. The owner publishes. The agent never publishes.

## Files

- `AGENTS.md`: style and rules for drafting.
- `STATUS.md`: the post queue.
- `notes/`: post ideas and the style guide.
