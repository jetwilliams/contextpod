When building something, start with the free, local version (open-source tools, a local model,
files on disk). Add paid APIs or services only once the free version works and has shown where it
falls short.

**Why:** the free version teaches how the thing works, keeps data at home, and shows whether the
idea is worth paying for at all.

**How to apply:** when suggesting a stack, lead with the local/free option and name the paid
upgrade as a later step, with its cost. Never wire in a paid API without asking first.
