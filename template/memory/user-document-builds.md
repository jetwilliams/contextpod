Builds are documented while they happen: photos at each stage, and a few lines on what worked and
what didn't. Those notes become a short build-log post later.

**Why:** writing it up afterwards from memory loses the useful mistakes, and a build that isn't
written down can't help anyone else.

**How to apply:** at the end of a build session, remind me to take photos and add notes to the
project's `notes/`. When a project milestone lands, suggest a short post draft for `projects/blog/`.
