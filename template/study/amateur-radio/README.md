# Amateur radio track

> Example: replace with your own.

**Summary:** studying for an entry-level amateur radio licence. Licence classes and syllabuses
differ by country, so the structure below is generic.

## Structure

| Folder / file | What goes in it |
|---|---|
| `notes/` | One file per syllabus topic: theory, regulations, operating, safety |
| `formulas.md` | Every formula with units and one worked example |
| `practice.md` | Practice-exam log: what you got wrong and why |

## How an assistant can help

- Work every calculation with units shown.
- Link theory to the projects in this pod (antennas for `projects/sky-watcher-mast/`).
- Check regulation answers against the official syllabus for my country, and say when unsure.
